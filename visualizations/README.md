
# Cyclistic Data Visualizations

This folder contains the visualizations created for the 2025 Cyclistic Bike-Share Analysis project using Tableau.

The visualizations explore differences between annual members and casual riders across:

- Overall trip share
- Rider composition by weekday
- Monthly rider trends
- Ride duration distribution
- Top starting stations
- Top ending stations
- Final analytical dashboard

These charts communicate the key findings of the project and support the business recommendations.
